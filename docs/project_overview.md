# Project Overview

This project focuses on long-document summarization using Large Language Models.

The goal is to build a document-agnostic pipeline that can process long TXT, PDF, and DOCX files.

The main pipeline is:

Long Document
→ Chunking
→ Chunk Summaries
→ Hierarchical Merge
→ Extract Support
→ Grounded Merge
→ Claim Verification
→ Repair
→ Final Verified Summary

The system has been tested on the GDPR and the EU AI Act.
